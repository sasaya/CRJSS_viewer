OR-ToolsまたはHiGHSでサイクリックジョブショップの最小サイクルとなる解を計算し、計算結果の解を簡易シミュレータに適用します
以下の機能があります。
- 現状投入されたジョブから一定周期ごとに最小サイクルを逐次計算して、機械への投入順番を調整する
- ジョブの投入前に最小サイクルを計算して、機械への投入順番だけをシミュレータに渡した場合
- ジョブの投入前に最小サイクルを計算して、最小サイクルと一致する時刻に投入するようにシミュレータに渡した場合

このコードの作成には生成aiを一部使用しています。

実行方法
```powershell
.\start.ps1
```
or
```powershell
.\start.ps1 -Config .\examples\small.json -Port 8082
```
